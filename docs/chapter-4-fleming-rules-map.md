## Interaction acceptance notes

- Learning question: which quantity is the input and which direction is the output for a motor or generator?
- State: active rule, four-shot teaching step, play/pause state, normal/reversed input.
- Consequence: reversing current or motion flips the shown force or induced current; the magnetic field stays N → S.
- Zero/invalid state: not applicable because this is a direction-only qualitative model; the caption states that it does not calculate magnitude.
- Controls: autoplay, pause/play, next shot, replay, direct rule and timeline selection.
- Accessibility: semantic buttons, live result label, reduced-motion autoplay opt-out, touch and keyboard controls.
- Responsive risk: the three synchronized panels stack on narrow screens; perpendicular directions retain ⊙ / ⊗ labels.
