# Repository agent instructions

Before creating, extending, or reviewing an interactive syllabus-aligned
teaching chapter in this repository, read and follow the matching skill:

- **Cambridge IGCSE Physics** — use
  [`skills/build-igcse-interactive-chapter/SKILL.md`](skills/build-igcse-interactive-chapter/SKILL.md).
- **Any other subject** (Math, Chemistry, Biology, Economics, …) or exam board —
  use the subject-neutral template
  [`skills/build-interactive-chapter/SKILL.md`](skills/build-interactive-chapter/SKILL.md),
  and fill in its subject profile
  ([`references/subject-profiles.md`](skills/build-interactive-chapter/references/subject-profiles.md))
  first.

Both skills share the same workflow: syllabus mapping, interaction design,
domain-correctness validation, browser testing, and phased publishing. Read the
skill's linked `references/chapter-blueprint.md` when planning a new chapter or a
substantial expansion.

Keep the repository copies of the skills as the canonical source. Do not
duplicate their workflow in another instruction file.
