# Repository agent instructions

Before creating, extending, or reviewing an interactive Cambridge IGCSE Physics
chapter, read and follow
[`skills/build-igcse-interactive-chapter/SKILL.md`](skills/build-igcse-interactive-chapter/SKILL.md).

Use the skill's syllabus-mapping, interaction-design, physics-validation,
browser-testing, and publishing workflow. Read its linked
`references/chapter-blueprint.md` when planning a new chapter or a substantial
expansion.

Keep the repository copy of the skill as the canonical source. Do not duplicate
its workflow in another instruction file.
